Starlink Group

Starlink Group is the official business website and automation portal for Starlink Group. This website includes a TikTok integration that allows authorized users to connect their TikTok account and publish approved video content through Starlink Group's backend automation workflows.

Connect TikTok Account

Authorized users can sign in with TikTok Login Kit and grant permission for Starlink Group to identify the connected TikTok account and publish user-approved videos using TikTok Content Posting API.

Connect with TikTok

How the TikTok integration works

  1. The authorized user clicks “Connect with TikTok”.
  2. The user authorizes Starlink Group through TikTok Login Kit.
  3. TikTok redirects the user back to the configured redirect URI with an authorization code.
  4. The backend automation workflow exchanges the authorization code for TikTok access credentials.
  5. The workflow publishes only user-approved video content to the authorized TikTok account.
