Starlink Group TikTok App

Starlink Group TikTok App is a web-based automation tool used by authorized Starlink Group users to connect their TikTok account and publish videos through n8n workflows.

Connect TikTok Account

Users sign in with TikTok Login Kit to authorize this app. After authorization, the app uses TikTok Content Posting API to upload or publish videos to the authorized user's own TikTok profile.

Connect with TikTok

How it works

  1. The user clicks “Connect with TikTok”.
  2. The user authorizes Starlink Group TikTok App using TikTok Login Kit.
  3. TikTok redirects the user back to the configured redirect URI with an authorization code.
  4. The backend or n8n workflow exchanges the code for access token, refresh token, and open_id.
  5. The workflow uses TikTok Content Posting API to upload or publish videos for the authorized TikTok account.
